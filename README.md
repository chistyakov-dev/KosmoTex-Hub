## 🚀 О проекте

KosmoTex Hub — это подпроект KosmoTex, созданный для открытого распространения знаний. Основная цель проекта — собрать в одном месте лучшие открытые материалы по космической тематике и сделать их удобными для изучения каждым человеком, независимо от возраста и возможностей.

Платформа считает открытость знаний в эпоху Интернета фундаментальной вещью, про которую начали забывать после появления платных курсов.

### 🌌 Ключевые разделы сайта:
* Главная страница — приветственное окно и путеводитель для новичков.
* Гостевая книга — раздел с описанием миссии проекта, ответами на главные вопросы и философией открытой информации.
* Материалы — полноценное хранилище книг и документов (например, уникальные материалы об истории космонавтики, такие как книга *«Лайка: собака, которая не вернулась»*).
